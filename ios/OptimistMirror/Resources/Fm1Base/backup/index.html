Back up {{NAME}}

Save what {{NAME}} keeps to a file on this computer, and load them back later. Connect the FM-1 with a USB cable. This page works in Chrome or Edge, and there is nothing to install.

Plug the FM-1 running {{NAME}} into this computer with a USB cable.

Is the FM-1 under another name?

A computer can show an FM-1's port under another device's name (a Mac remembers names by USB socket). This page asks only the ports with an FM-1's usual names by itself. If your FM-1 is in this list, press Try on it.

    Back up

    This saves everything to a .{{EXT}} file. That includes {{HOLDS}}. {{NAME}} can keep playing. If you have changes that aren't saved yet, stop {{NAME}} first so they go in the file too.

    Restore

    This puts a backup back on {{NAME}}, and it replaces everything there. Stop {{NAME}} first. {{NAME}} checks the whole file before anything changes. Then its screen asks RESTORE FROM USB? Press SEL on the FM-1 to restore, or HOME to keep what you have.

    • A backup doesn't hold the button calibration: it belongs to the FM-1.
      • {{EXTRA}}
    • A cut cable or a damaged file changes nothing. Even a power cut during the write leaves either what was there or the backup, never a mix.
    • The browser asks once for permission to use MIDI with SysEx. Allow it, and close other apps that use the FM-1's MIDI first.
