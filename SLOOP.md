# SLOOP is now Optimist

This firmware was SLOOP-plus; it is called **Optimist** now. The manual is [OPTIMIST.md](OPTIMIST.md), and the
firmware builder is described in [docs/BUILDER.md](docs/BUILDER.md).

Optimist is based on SLOOP (isod89/sloop-fm1) and Felucca / Melodee (hugelton/Felucca, keremimo/melodee; FM6 by
Kerem Kilic), with parts from X0X (charlesvestal/fm1-x0x, Charles Vestal). GPL-3.0: see LICENSING.md.
